# ✦ AI Hub

AI 서비스를 한곳에서 탐색하고 바로 이동할 수 있는 링크 모음 페이지입니다.

## 화면 구성

| 영역 | 설명 |
|---|---|
| **상단 메뉴** | 대 카테고리 탭 (전체 / AI 어시스턴트 / AI 창작 도구 / AI 개발 도구 / 플랫폼 & 리소스) |
| **사이드 메뉴** | 소 카테고리 필터 + 서비스 개수 표시 |
| **카드 그리드** | 서비스 아이콘 · 이름 · 설명 · 태그 · 방문 버튼 |
| **검색창** | 상단 우측 — 사이트명 · 설명 · 도메인 실시간 검색 |
| **정렬 버튼** | 기본순 / 이름 오름차순 / 이름 내림차순 |

## 주요 기능

- **카테고리 필터** — 상단 탭 클릭으로 대 카테고리 전환
- **소 카테고리 필터** — 사이드바에서 세부 분류 선택
- **실시간 검색** — 사이트명·설명·도메인 기준 즉시 필터링 + 키워드 하이라이팅
- **정렬** — 기본순 / 이름 오름차순 / 이름 내림차순
- **키보드 단축키** — `/` 검색창 포커스, `Esc` 검색 초기화
- **다크 테마** — 다크 모드 전용 UI
- **반응형** — 모바일(768px 이하) 레이아웃 지원

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (단일 파일, 외부 의존성 없음)
